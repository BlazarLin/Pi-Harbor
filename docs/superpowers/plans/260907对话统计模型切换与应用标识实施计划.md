# PI-Harness 对话统计、模型切换与应用标识实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 发布 PI-Harness 1.1.0，提供每轮耗时/token、模型下拉切换、项目目录右键打开及完整应用图标与版本信息。

**Architecture:** Core 在读取当前有效分支时聚合轮次统计；App ViewModel 复用 pi RPC 获取/切换模型并统计实时轮次。WPF 只负责展示和用户事件，目录启动参数由独立小组件构造，图标由仓库脚本确定性生成。

**Tech Stack:** .NET 10、WPF、C# 12、pi 0.84.4 RPC、PowerShell 5.1；无第三方 NuGet 或运行时依赖。

## Global Constraints

- 不增加第三方依赖。
- 不修改或写回用户 JSONL。
- 模型列表只来自 `get_available_models`，切换只使用 `set_model`。
- 历史轮次以用户消息为开始，以下一用户消息前最后记录为结束；实时轮次以 `agent_settled` 为结束。
- 模型列表获取失败不得阻断会话。
- 版本统一为 1.1.0。
- 新代码文件必须有创建日期、功能和目的说明。
- 所有测试输出中文并说明验证目标。

```csharp
public static ProcessStartInfo CreateStartInfo(string directory)
{
    var path = Path.GetFullPath(directory);
    if (!Directory.Exists(path)) throw new DirectoryNotFoundException(path);
    var info = new ProcessStartInfo("explorer.exe") { UseShellExecute = true };
    info.ArgumentList.Add(path);
    return info;
}
```

PowerShell 脚本使用 WPF `DrawingVisual` 与 `PngBitmapEncoder` 生成七个尺寸，再按 ICO 文件格式组合；csproj 设置 `ApplicationIcon`、Version、AssemblyVersion、FileVersion、InformationalVersion。
