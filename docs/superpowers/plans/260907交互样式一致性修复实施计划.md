# PI-Harness 交互样式一致性修复实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复模型框、项目树和右键菜单的样式与交互缺陷，并由自动化和真实鼠标操作完成验收。

**Architecture:** 保持现有 WPF/MVVM 结构，不增加依赖。样式状态放在 XAML 模板内，项目组鼠标选择规则由窗口事件处理器完成，契约测试直接检查模板和事件边界。

**Tech Stack:** C#、WPF、.NET 10、现有无第三方依赖测试框架、Windows UI Automation。

## Global Constraints

- 不新增第三方依赖。
- 不改变 pi RPC、会话读取和文件夹打开业务逻辑。
- 所有新增 Git 提交信息使用中文。
- 必须自行完成自动化、Release 启动和真实 UI 交互验收。
