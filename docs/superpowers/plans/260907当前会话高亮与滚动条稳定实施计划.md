# 当前会话高亮与滚动条稳定 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 当前会话在侧栏持续高亮，并让消息区滚动条滑块在大会话不同位置保持固定视觉长度。

**Architecture:** 当前会话状态由 `SelectedSessionPath` 驱动并存放在会话 ViewModel 中，项目树重建时按路径恢复。滚动条保留项目级虚拟化，模板显式同步滚动值，并用固定 DIP 长度隔离虚拟化范围估算变化；内部 QA 直接测量五个滚动位置的滑块长度。

**Tech Stack:** .NET 8、WPF、C#、XAML、自研控制台测试框架、Git。

## Global Constraints

- 不增加第三方依赖。
- 保留详细对话的 `Standard` 虚拟化、页缓存和项目滚动。
- 所有提交信息使用中文。
- 使用真实大体量只读会话执行滚动和视觉验收。
- 只暂存本任务文件，不吸收无关工作区变更。

### Task 2: 固定滚动条滑块和运行时测量

**Files:**
- Modify: `tests/PIHarness.Tests/ConversationUiContractTests.cs`
- Modify: `tests/PIHarness.Tests/ScrollQaContractTests.cs`
- Modify: `src/PIHarness.App/Themes/Colors.xaml`
- Modify: `src/PIHarness.App/MainWindow.xaml.cs`

**Interfaces:**
- Consumes: 消息区 `ScrollViewer` 和 WPF `ScrollBar`/`Track`/`Thumb`。
- Produces: 固定 56 DIP 滑块、`ScrollQaStep.ThumbLength`、`TEST-UI-06`。

- [ ] **Step 1: 写入失败测试**

增加 XAML 合同断言：`PART_Track` 显式绑定滚动范围和值，垂直 `Thumb` 高度为 56。增加 QA 合同断言：报告包含 `TEST-UI-06`、`ThumbLength` 和 `thumb=`。

- [ ] **Step 2: 验证测试失败**

Run: `dotnet run --project tests/PIHarness.Tests/PIHarness.Tests.csproj -c Release`

Expected: 新滚动条合同和 QA 长度证据缺失，测试失败。

- [ ] **Step 3: 实现稳定模板**

`PART_Track` 显式设置：

```xml
Minimum="{TemplateBinding Minimum}"
Maximum="{TemplateBinding Maximum}"
Value="{TemplateBinding Value}"
Orientation="{TemplateBinding Orientation}"
```

垂直 `Thumb` 设置 `Height="56"`；水平模式触发器将高度恢复为自动并设置 `Width="56"`。不绑定 `ViewportSize`，让 `Track` 使用滑块显式期望尺寸。

- [ ] **Step 4: 增加滑块长度自动验收**

在五个滚动步骤布局完成后定位消息滚动区的垂直 `ScrollBar` 和 `Thumb`，记录 `ActualHeight`。报告新增：

```text
[通过] TEST-UI-06：五个阅读位置的滚动条滑块长度差值不超过 1 DIP
```

任一位置找不到滑块、长度无效或最大差值超过 1 DIP 时 QA 返回失败。

- [ ] **Step 5: 运行测试并提交**

Run: `dotnet run --project tests/PIHarness.Tests/PIHarness.Tests.csproj -c Release`

Expected: 全部测试通过。

Commit: `修复：稳定大会话滚动条滑块长度`
