# PI-Harness 详细对话滚动 Top 10 优化实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复大会话滚轮阅读时闪烁、跳位和自动回底，并补齐可恢复、可观察、可回归的阅读体验。

**Architecture:** 保留 WPF UI 虚拟化，以同步历史 Markdown、Standard 容器虚拟化、项目锚点滚动和一页缓存消除二次布局与回收污染。使用独立滚动协调器管理跟随意图，ViewModel 提供流式/展开/加载状态，窗口只负责把输入和 ScrollViewer 事件桥接到状态机。

**Tech Stack:** .NET 8、WPF、C# 12、内置 RenderTargetBitmap、现有无第三方依赖测试运行器。

public sealed class ChatScrollCoordinator(double bottomThreshold)
{
    public bool IsFollowingLatest { get; private set; } = true;
    public void Reset() => IsFollowingLatest = true;
    public void OnUserWheel(int delta) { if (delta > 0) IsFollowingLatest = false; }
    public void OnViewportChanged(double distanceFromBottom) =>
        IsFollowingLatest = distanceFromBottom <= bottomThreshold;
    public void ReturnToLatest() => IsFollowingLatest = true;
}
```

private static void OnMarkdownChanged(DependencyObject value, DependencyPropertyChangedEventArgs args)
{
    var control = (MarkdownTextBlock)value;
    control._renderTimer.Stop();
    if (control.IsStreaming) control._renderTimer.Start();
    else control.RenderMarkdown();
}
```
