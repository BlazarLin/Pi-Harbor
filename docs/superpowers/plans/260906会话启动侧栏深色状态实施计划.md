# PI-Harness 会话启动侧栏深色状态实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 消除进入会话且 pi 正在启动时左侧会话区域变白的问题。

**Architecture:** 保持 TreeView 的 Enabled 视觉状态，改用命中测试绑定阻止启动期间的鼠标切换；选中后立即转移键盘焦点，ViewModel 状态检查继续负责业务防重入。

**Tech Stack:** C# 14、.NET 10、WPF、现有无第三方依赖测试程序。

## Global Constraints

- 不新增依赖，不重写 TreeView 系统模板。
- 不改变会话加载、状态机和侧栏正常态配色。
- Starting 状态不得出现白色会话区域，也不得启动第二个会话。
