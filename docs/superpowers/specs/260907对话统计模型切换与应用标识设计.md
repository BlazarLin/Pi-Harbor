# PI-Harness 对话统计、模型切换与应用标识设计

日期：2026-09-07
版本目标：1.1.0

## 目标

在不增加第三方依赖、不破坏大会话稳定滚动的前提下，增加每轮耗时与 token、模型选择、项目文件夹快捷打开、软件图标和版本号。

## 已确认的数据契约

- 本机 pi 版本为 0.84.4。
- RPC `get_available_models` 返回所有已配置模型，`set_model` 接收 `provider` 与 `modelId`。
- assistant 与可选的 toolResult 消息包含 `usage.input/output/cacheRead/cacheWrite/reasoning/totalTokens`。
- JSONL 消息内 `timestamp` 是开始时间，条目外层 ISO `timestamp` 是该消息写入完成时间；一次用户轮次可能包含多次 assistant/toolResult。
- RPC `agent_settled` 表示重试、压缩重试与排队跟进均已结束，是实时轮次的结束边界。

## 方案选择

采用 pi 原生 RPC 与 JSONL 字段作为唯一数据源。拒绝只显示会话总量，因为它不满足“每轮”；拒绝解析 pi 配置文件，因为模型配置格式不是稳定的 UI 契约。

## 功能设计

### 1. 每轮耗时与 token

历史会话按当前有效分支顺序扫描：遇到 user 开始一轮，累计直到下一条 user 或分支末尾。输入、输出、缓存读写、推理和总 token 累加 assistant/toolResult usage；耗时从 user 消息时间到最后一条相关记录的外层完成时间。每轮结束后插入一个 `TurnMetrics` 显示项：

`⏱ 42.6 秒  ·  Tokens 12,340（输入 2,140 / 输出 620 / 缓存 9,580）`

没有 usage 的旧记录仍显示耗时；时间字段不完整时显示 token，不伪造耗时。实时对话从发送成功前启动高精度计时，在所有 `message_end` 中累加 usage，在 `agent_settled` 追加同样的统计项。中止或模型错误也结束本轮并显示已产生的数据。

### 2. 模型选择

标题栏右侧增加固定宽度下拉框，内容为 `显示名 · provider/id`，支持键盘首字母搜索。会话 RPC 就绪时并行请求 `get_state` 与 `get_available_models`，当前模型自动选中。

仅 Ready 状态允许切换。选择其他模型后发送 `set_model`，切换期间显示“正在切换模型…”，禁用发送、会话切换和模型框；成功后更新当前模型，失败则恢复原选择并显示具体 pi 错误。列表为空时显示当前模型文本但禁用选择。

### 3. 项目目录快捷打开

仅项目分组节点提供右键菜单“在文件资源管理器中打开”。使用 `explorer.exe` 的独立参数传递绝对路径，不拼接命令字符串；目录不存在时在状态栏显示错误，不启动进程。会话节点不显示该菜单。

### 4. 图标与版本

- 版本号：1.1.0，同时写入 AssemblyVersion、FileVersion 和 InformationalVersion。
- 窗口标题显示 `PI-Harness 1.1.0`，侧栏产品名下显示 `v1.1.0`。
- 应用图标为深色圆角方块、紫色 PI 字形和连接节点；提供 16/24/32/48/64/128/256 px 多尺寸 ICO。
- 图标由仓库内无第三方依赖脚本确定性生成，源脚本和 ICO 一同纳入 Git；WPF 窗口与 EXE 均使用该图标。

## 代码边界

- `PIHarness.Core`：扩展历史数据模型和分支内轮次统计，不涉及 WPF。
- `PIHarness.App` ViewModel：模型列表、切换状态、实时轮次统计与版本文本。
- `PIHarness.App` Presentation：资源管理器启动参数构造。
- XAML：统计模板、模型下拉框、项目右键菜单、版本与图标展示。
- `scripts`：确定性生成 ICO，不依赖外部图像库。

## 错误与兼容策略

- 数值字段缺失或类型错误按 0 处理，不影响正文加载。
- 外层时间早于开始时间时不显示耗时。
- `get_available_models` 失败时会话仍可使用当前模型，不让辅助功能阻断对话。
- `set_model` 失败不改变最终选中项。
- 旧 JSONL 不迁移、不写回。
- 文件夹打开只接受已存在的绝对目录。

## 验收

- 构造两轮含多次工具调用的 JSONL，验证每轮 token 不串轮、耗时边界正确。
- 真实 121 MB 会话仍在性能基线内完成读取并显示轮次统计。
- fake RPC 验证模型列表解析、当前项选中、成功切换、失败回滚和 Streaming 禁用。
- 文件夹启动参数测试覆盖空格、中文路径和不存在路径。
- EXE 文件属性为 1.1.0，窗口/侧栏版本一致，ICO 含多个尺寸。
- 最终发布版视觉截图验证统计行、模型框、右键菜单、图标和版本；既有滚动 QA 不回归。
