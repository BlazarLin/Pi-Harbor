# PI-Harness 会话启动侧栏深色状态设计

## 问题

进入已有会话后，状态切换为 `Starting`，`CanSwitchSession` 变为 false。当前 TreeView 将该值绑定到 `IsEnabled`，Windows 默认禁用模板把原本透明的会话区域绘制成白色。

## 方案

TreeView 保持 Enabled，不再触发系统禁用配色；将 `CanSwitchSession` 绑定到 `IsHitTestVisible`，启动期间只关闭鼠标命中。选中会话后立即把焦点移到输入框，避免 TreeView 在启动期间继续接收键盘导航。`OnSessionSelected` 和 `OpenSessionAsync` 现有状态检查继续阻止重复切换。

不重写系统 TreeView 模板，不增加遮罩层，不改变 ViewModel 状态机。

## 验收

- Starting 状态会话区域保持 `SidebarBrush` 深色背景。
- Starting 状态 TreeView 不接受鼠标输入，键盘焦点不留在 TreeView。
- Ready 后 TreeView 恢复鼠标选择。
- 自动化测试、真实大会话截图和发布包构建全部通过。
