# PI-Harness 交互样式一致性修复设计

## 目标

修复模型选择框、项目树父级悬停和项目右键菜单的视觉/交互缺陷，使所有新增功能遵循 PI-Harness 现有暗色主题，并通过自动化与实机鼠标操作自行验收。

## 设计

### 模型选择框

- 移除组合框内部 `ToggleButton` 的系统默认视觉，只保留自绘边框、文本和箭头。
- 无会话或无模型时显示“选择会话后可切换模型”，不显示空白灰条。
- 正常、悬停、键盘聚焦、下拉展开和禁用状态使用 `PanelBrush`、`HoverBrush`、`AccentBrush` 与统一透明度。
- 下拉项继续使用暗色模板，选中项和悬停项不回退到系统白色主题。

### 项目树

- 悬停背景只由当前 `HeaderBorder.IsMouseOver` 决定，子会话区域不再触发父项目背景。
- 项目组不进入 `IsSelected` 状态；鼠标左键点击项目标题仅切换展开状态。
- 会话项保持现有选中行为。

### 右键菜单

- 全局为 `ContextMenu` 和 `MenuItem` 提供暗色模板。
- 菜单使用暗色面板、主题边框、圆角及 `HoverBrush` 悬停反馈。
- “在文件资源管理器中打开”功能和安全参数传递逻辑保持不变。

## 验收标准

- 无会话时模型框有明确占位文字，无系统灰色块。
- 模型框悬停、聚焦和展开时无白底、原生灰底或突兀边框。
- 鼠标在任意子会话上移动时，父项目标题背景不变化、不闪烁。
- 项目组鼠标点击后不保持选中背景，仅展开或折叠。
- 项目右键菜单为统一暗色，悬停反馈清晰。
- 全量自动化测试、Release 启动冒烟、真实 UI 鼠标操作与截图全部通过。
- 本次及后续 Git 提交信息使用中文。
