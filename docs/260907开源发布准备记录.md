# Pi Harbor 1.3.1 开源发布准备

日期：2026-09-07。用户选择 MIT，允许将已验收改动提交到本地。发布步骤见 [GitHub 发布指南](GITHUB_RELEASE.md)，功能和使用边界见 [README](../README.md)。

## 本轮实现

- “回到最新”复用主题紫色，使用 16 DIP 圆角，支持鼠标和键盘状态。
- 会话行显示相对活动时间及全局最新标识，每分钟刷新；自动更新保留项目折叠与当前会话高亮。
- 文件监听覆盖新增目录、重命名与持续写入，5 秒元数据轮询补偿漏事件与根目录稍后创建；未变化的文件复用索引。
- README 记录 Pi 0.84.3，添加实际 WPF 脱敏截图。截图前先遮挡真实项目与会话标题，正文用演示内容。
- 增加 MIT、贡献指南、安全报告说明、变更记录、Issue/PR 模板、CI 和 Dependabot。
- 配置当前用户安装器、便携 ZIP、运行库许可和 SHA-256；版本标签工作流创建 Release 草稿。
