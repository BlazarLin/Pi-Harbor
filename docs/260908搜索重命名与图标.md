# Pi Harbor 1.4.0：搜索、重命名与图标

日期：2026-09-08。用户要求全局搜索、自定义会话名称，以及无黑边、右下带 harbor 的图标；比较 A/B/C 后选择 **B：底部色带**。

## 使用方式

- 左侧搜索框输入关键词，或按 `Ctrl+Shift+F` 聚焦。输入停顿后开始搜索，`Enter` 立即搜索，`Esc` 清空。结果显示会话名称、项目、匹配来源和片段；点击打开当前会话分支。
- 右键普通会话或搜索结果 → 重命名；会话列表有焦点时也可按 `F2`。支持 120 字符以内的本机名称和恢复默认。
- 正式图标采用 B 版紫色底部色带，移除原黑色外框。32 像素及以上含 harbor 字样，16/24 像素保留可辨识的 Pi 标识。

## 数据与性能边界

搜索会话名称、项目路径、全部已保存历史分支的消息文字，包括用户、助手、思考与工具输出。大小写不敏感，按连续文字匹配。图片 Base64、协议字段、工具调用参数不参与匹配。流式逐行读取并仅保留最多 100 个会话片段，超限、损坏记录及无法读取的文件会提示。后台搜索支持取消；目录刷新期间合并后续请求，避免持续写入使查询反复重启。

当前点击搜索结果打开该会话当前分支，不自动定位历史命中行；其他历史分支的命中内容可从片段中确认。全文仍需读取相关文件，超大目录首次搜索可能较慢，界面保持可操作。

名称保存到 `%LOCALAPPDATA%\Pi Harbor\session-names`，通过会话绝对路径的哈希关联。每个名称独立原子保存。重命名不启动 Pi、不修改 JSONL、不改变最近交流时间；名称仅用于本机 Pi Harbor，不同步到 Pi 终端。移动会话文件路径后需重新命名。
